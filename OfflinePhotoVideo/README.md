# Offline Photo & Video (Android)

Kotlin + Jetpack Compose + CameraX + NanoHTTPD + ZXing. Tidak ada cloud/login.

## Build
1. Buka folder ini di Android Studio (Koala atau lebih baru, JDK 17) lalu Sync Gradle.
2. Jalankan di HP asli (kamera tidak berfungsi di emulator biasa).
3. APK debug: Build > Build APK(s).

## Cara pakai
KAMERA: ambil foto/video -> GALERI: PILIH -> QR -> HP lain scan -> halaman download terbuka di browser.
Kedua HP harus di Wi-Fi yang sama, atau HP lain tersambung ke hotspot HP utama.
Biarkan aplikasi tetap terbuka selama sharing.
